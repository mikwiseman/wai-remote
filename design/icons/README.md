# WAI Remote icon exploration

Seven original concepts generated with the built-in imagegen tool on 11 October 2026. The brief: a simple, expressive remote-computer identity that also survives as a small monochrome menu bar symbol. No lettering, complex texture or miniature UI.

| Concept | Decision |
| --- | --- |
| 01 Portal | **Selected.** Open frame and a separate square: two spaces brought together. Strong single-color silhouette, simple enough at menu bar sizes. |
| 02 Ribbon | Energetic, but the folded R becomes a less distinct shape in one color. |
| 03 Windows | Immediately suggests two screens; the overlapping middle is crowded at small sizes. |
| 04 Orbit | Friendly connection motif, but heavier dots compete with the frame. |
| 05 Reach | Clear remote-control meaning; the cursor makes it less distinctive. |
| 06 Fold | Elegant large icon; too close to an open book and loses the fold in monochrome. |
| 07 Near | Bold, but resembles code brackets more than a screen connection. |

The menu bar uses a black/transparent template, so macOS supplies the appropriate appearance in light, dark and selected states. The application icon uses a square source and the system icon mask. The purple screen-sharing indicator is macOS privacy UI, not WAI Remote's icon.

Sources: [Apple app icons](https://developer.apple.com/design/human-interface-guidelines/app-icons/), [menu bar extras](https://developer.apple.com/design/human-interface-guidelines/the-menu-bar#Menu-bar-extras), [Icon Composer](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer).

# WAI Remote 0.3.7 — Mac 79

Full-desktop clicks activate the selected application from a background WAI host. Hosted macOS buttons and popup controls follow their exact link to the selected outer window. The remote pointer stays separate; single-window grants keep background input. Save-dialog keyboard and menu-selection corrections remain included.

Hosted popup actions are enabled only inside a verified remote subtree with a matching WindowServer owner, parent and virtual-window identity. Open menus receive keys at their exact verified menu window. Selection preserves typing only in the proven originating host window. Ambiguous branches, other sheets and changed windows are rejected. Native XPC tests cover format selection, continued Unicode typing and Escape in attached and standalone save panels.

Keyboard target discovery has the same 50 ms maximum as button lookup, allowing slower accessibility replies under load. Successful lookups return immediately; no sleep or input retry is added. Native fixtures use real application lifecycle acknowledgments and bounded XPC control discovery. Default-budget routing checks and one-click, foreground, scope and pointer assertions remain; repeated modal-scope checks use a separate test budget.

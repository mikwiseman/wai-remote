# WAI Remote 0.3.6 — Mac build 67

Video keeps its full 60 fps ceiling again. Build 66 lowered the frame rate
after high-QP seconds; with ScreenCaptureKit sending frames only on change,
the last frame of a burst could be dropped and never re-sent. A static screen
is now refined by re-sending its last frame briefly after each change, so text
sharpens and a frame lost on the way still arrives.

Updated apps try a direct route on the physical network before the relay, for
example two Macs on one LAN. Addresses of VPN tunnels and loopback are never
offered, because direct routes through a tunnel stalled input. The relay stays
the fallback, and the two devices now learn each other's network addresses.

Keyboard and clipboard input is more reliable in independent mode. Command
shortcuts aimed at a background app press the matching item in that app's
menu, because background apps ignore posted menu shortcuts. Pasting text types
it, without formatting, so background apps receive it; files and images keep
Command-V. A paste that cannot finish now shows an error. The host keeps its
typing target across focus changes and stalls, input already in flight
survives a stall, and only exact viewer shortcuts stay on the viewer.

Install this update on **both Macs**: direct routes need it on both ends, and
the input and shortcut fixes are split between host and viewer.

Validation: 183 package tests, the gateway race suite, a production-relay
session benchmark, and an in-process direct-route check. A real two-Mac
session after the update is still required to confirm menu shortcuts in
specific background apps and the direct LAN route.

# WAI Remote 0.3.5 — Mac build 66

The host now responds to degraded H264 encoding by temporarily reducing frame
cadence while preserving native desktop resolution. It restores cadence
gradually after sustained clear frames. On a healthy connection it retains the
60 fps ceiling. This trades smoothness for readable detail on a constrained
connection; it does not increase the network's available bandwidth.

Independent clicks in the foreground application no longer send an off-window
activation gesture first. That gesture could dismiss a menu or popover before
the intended click and added approximately 166 ms of waiting. Background apps
retain their compatibility sequence. Window-local coordinates are recomputed
after activation, including movement during its waits.

Install this update on the **Mac sharing its screen**. The host changes also
benefit existing Mac, iPhone/iPad and browser viewers. No iOS binary change is
required for these fixes.

Validation includes deterministic foreground/background click routing,
coordinate movement during activation, cancellation, hardware H264 tests,
and an opt-in generated Retina text benchmark. The benchmark has no desktop
capture or private content. A real lesson on two separate computers remains
necessary to verify the reported symptoms on that particular network.

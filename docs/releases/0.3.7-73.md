# WAI Remote 0.3.7 — Mac 73 candidate, iPhone 72

Codex and other local agents can use WAI Remote through its bundled Python 3 CLI: connect to a saved computer, inspect decoded remote screenshots, click, scroll, press keys, type exact Unicode and disconnect. Commands use the ordinary viewer connection and existing host permissions. They do not depend on the MacBook's pointer position, keyboard layout or clipboard.

The app exposes a private same-user Unix socket, with bounded requests and no TCP listener. Input requires a screenshot token tied to the current session, permissions, surface geometry and video track. A newer video frame alone does not invalidate the token. Requests that expire before execution cannot run later; a result not yet known is reported as `execution_pending`. Input is reported as `submitted`; a subsequent decoded screenshot must establish its effect.

Thirteen focused native tests pass, including real CLI/socket exchange, Unicode, PNG orientation, context invalidation, private file permissions and timeout cancellation. Independent review passed after correcting an expired-request race. A further integration test passed through the actual relay: CLI commands crossed production WebRTC, click and exact Unicode input changed subsequent decoded PNGs, and stale epochs or revoked permissions blocked further input. The host was synthetic; CI and installed-app acceptance are pending. The Mini remains unavailable, so live Mini control is not yet verified.

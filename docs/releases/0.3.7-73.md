# WAI Remote 0.3.7 — Mac 73 test candidate, iPhone 72

Codex and other local agents can use WAI Remote through its bundled Python 3 CLI: connect to a saved computer, inspect decoded remote screenshots, click, scroll, press keys, type exact Unicode and disconnect. Commands use the ordinary viewer connection and existing host permissions. They do not depend on the MacBook's pointer position, keyboard layout or clipboard.

The app exposes a private same-user Unix socket, with bounded requests and no TCP listener. Input requires a screenshot token tied to the current session, permissions, surface geometry and video track. A newer video frame alone does not invalidate the token. Requests that expire before execution cannot run later; a result not yet known is reported as `execution_pending`. Input is reported as `submitted`; a subsequent decoded screenshot must establish its effect.

Thirteen focused native tests pass, including real CLI/socket exchange, Unicode, PNG orientation, context invalidation, private file permissions and timeout cancellation. Independent review passed after correcting an expired-request race. A further integration test passed through the actual relay: CLI commands crossed production WebRTC, click and exact Unicode input changed subsequent decoded PNGs, and stale epochs or revoked permissions blocked further input. Clean Swift CI also passed with the decoded PNG artifacts retained.

Apple notarization, signed preview publication and the installed MacBook update from 72 to 73 passed. The normal public feed remains on 72. When the Mini became reachable, installed CLI commands opened a new TextEdit document, entered exact mixed-language text including emoji, and scrolled it. Subsequent decoded screenshots verified each effect. The live test also found multiline loss at native text-event boundaries and input not reaching a modal save sheet. Build 73 therefore remains a test candidate; build 74 will address these defects before normal publication. No claim is made that the earlier Mini outage's cause was established.

# WAI Remote 0.3.7 (70)

1 November 2026. An active MacBook connection made the iPhone retry “Mac занят” forever. The test connection was explicitly disconnected. The iPhone now explains that another device is connected and offers **Подключиться здесь** when the Mac supports switching. Older hosts show a disconnect-and-retry instruction.

Switching requires an existing, unexpired control grant and one explicit signed request for the exact current session. Passive recovery cannot take the session back. Stale requests, read-only or lab-only grants, first-time invitations, pending approval and an owner's pause cannot displace a session. If the Mac became free before the request arrived, the connection proceeds normally. Switching leaves stored permissions and expiry unchanged.

# WAI Remote 0.3.7 — Mac 81

Mac 81 stops accessibility button searches at the owning window or sheet. This avoids unnecessary parent-process queries and preserves the remaining time for hosted controls. A native regression failed before the change and passed afterward. The click, menu, typing and own-window activation fixes from [Mac 80](0.3.7-80.md) remain included.

Exact artifact source `b799faefe011d254eac491769231bb38e1087bc0` passed both [PR CI](https://github.com/mikwiseman/wai-remote/actions/runs/41344812616) and [push CI](https://github.com/mikwiseman/wai-remote/actions/runs/41344808479): each ran 263 Swift tests with three existing skips and zero failures, 45 iOS tests, gateway race tests and the web build. The universal release package was [built separately](https://github.com/mikwiseman/wai-remote/actions/runs/41345514460) from that exact source, then signed and notarized.

The signed normal Sparkle feed and public DMG were independently downloaded and verified. Both the MacBook and Mini completed 80→81 through Sparkle, preserving saved computers and access. The Mini reconnected automatically. Its installed executable matched the release hash, and its signature, stapled ticket and Gatekeeper checks passed.

Live MacBook→Mini control through the installed agent CLI and WAI WebRTC passed:

- Native button 0→1, Unicode text, and a background-window button click 1→2.
- Scrolling down 240 points moved the first visible line from the header to line 18; scrolling up 120 points returned to line 9.
- Save dialog format-menu opening and selection, followed by Unicode filename typing.
- Cancel and Delete each worked on the first click while the dialog was behind Terminal. Delete discarded only the newly created test document.

Owned test windows were closed and the viewer disconnected. Private evidence is retained in `.runtime/agent81/live-acceptance.json` and `.release/publish-0.3.7-81/`; desktop screenshots are not published.

The DMG is 20,337,087 bytes, SHA-256 `65d3dcd454f57f828b5285a07be7e6b187177373501234a0fa1a5c04bafd5bf7`. It supports Apple Silicon and Intel on macOS 15 or later.

iPhone TestFlight remains 0.3.7 (73). Physical iPhone scrolling feel, input-to-photon latency and LTE/Wi-Fi handover remain unverified. The [observed video pauses](../PERFORMANCE.md#build-80-device-evidence-1-november-2026) are a separate unresolved performance issue; these input checks do not establish smoothness on every network.

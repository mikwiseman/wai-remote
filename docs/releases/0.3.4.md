# WAI Remote 0.3.4

macOS build 65 · 19 October 2026

## Changes

- Use independent input by default from the primary sharing action. The persistent Settings switch selects a shared system pointer when explicitly disabled; changes apply to the next connection. Existing peer scopes and approval deadlines are preserved.
- Move the host's independent pointer with a vector layer in a stationary panel. Avoid repeated window movement, CPU drawing and synchronous visibility/level queries during display hover.
- Negotiate the Mac viewer's local pointer inside its signed offer. Exclude the host's blue overlay from capture only for that capability; older Mac, browser and touch viewers retain their captured pointer.
- Initially select Until Revoked for new approvals. One-hour and 24-hour permissions remain available and existing expiry is still enforced.
- Add mode, session-end, approval-expiry and numeric transport-error diagnostics. Enforce a strict event/field/type schema before writing the ordinary local journal. See [privacy and diagnostic scope](../DIAGNOSTICS.md).

## Measurement limits

The isolated pointer benchmark did not reproduce the earlier half-second dispatch stalls. No new two-physical-Mac active-input, optical-latency or equivalent AnyDesk comparison was available for this release. Native Retina capture, codec and bitrate settings are unchanged. Both Macs must update to use the local-pointer capability.

The Mini journal cannot attribute an interruption from a lesson hosted on another computer. Its earlier signaling-loss records include retries and do not establish a matching number of video-session drops. The old one-hour approval default is a possible cause of a long session ending, not a confirmed diagnosis of that lesson. Existing temporary approvals are not silently extended.

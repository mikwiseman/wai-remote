# WAI Remote 0.3.0

macOS build 54 · iOS build 52 · 16 October 2026

## Changes

- An opened access grant persists across application relaunch and login. Display sleep no longer closes it. A bundled login helper restores the app after an unexpected exit; explicit Close Access cancels restoration.
- Trusted Mac, iOS and browser clients retry transient failures automatically. Silent signaling sockets are replaced, expired relay configuration is refreshed, and disconnected input is released before a new session starts.
- Window control has a separate pointer and a prominent entry point. The owner's desktop pointer stays independent. A window grant never expands to the full desktop.
- Native Liquid Glass on macOS/iOS 26, material fallbacks on older systems, and simpler connection screens. The native iOS viewer includes saved computers, touch control, text input and foreground recovery.

## Verification

- Swift suite: 111 tests, zero failures; one opt-in WebRTC integration test skipped.
- Go race tests and browser production build passed.
- A native iPhone simulator controlled the Mac's input test window through the public TURN service for 612 seconds without a host stop. Clicks and text were observed on the receiving Mac. After a deliberate 20-second host stall, the viewer reconnected automatically and another click incremented the counter exactly once.
- The final installed Mac build was forcibly terminated in an isolated test. Its bundled helper relaunched it in 23.7 seconds without a manual launch; the UI showed access open and both original trusted devices remained unchanged.
- Developer ID signatures and Apple notarization verified for the universal app and DMG. The mounted DMG's app was checked independently. App Store Connect processed iOS build 52 as VALID and placed it IN_BETA_TESTING for the existing internal group.

The network test used a simulator and host on one physical Mac through the public relay. It does not replace a two-device test on independent physical networks. Lock/unlock and cold-login behavior still require an attended physical-device check. Independent window input depends on the target application; some native shortcuts/dialogs require full-screen control. The app does not provide access through the macOS login or lock screen.

## Distribution

The signed Mac DMG and ZIP are available as manual downloads, and the public Sparkle feed now offers build 54. The original Ed25519 key was provisioned on the release Mini and backed up in 1Password without changing the installed application public key. The public payload checksum and Ed25519 signatures were verified; a MacBook installed the update from build 50 to 54 through Sparkle and retained its saved computers. Both macOS and iOS signing identity checks passed on the Mini.

iOS build 52 was uploaded to the existing internal TestFlight group. Invitations were resent to the owner's two existing tester accounts, and the owner confirmed that WAI Remote 0.3.0 (52) appeared in TestFlight on the iPhone.

The iOS upload warns that the third-party WebRTC binary does not include its dSYM. The application archive and application symbols are retained; the warning did not block validation or TestFlight availability.

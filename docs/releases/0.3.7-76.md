# WAI Remote 0.3.7 — Mac 76 candidate, iPhone 73 candidate

Full-desktop clicks bring the selected window and its app forward while keeping the remote pointer separate. The clicked frame is captured before activation; no click is redirected after a window moves. Hover, scrolling and held drags do not activate another app. Existing single-window grants keep background input.

Save-panel keyboard routing identifies the owner of the exact remote window linked to the selected sheet. This covers compact panels on macOS 26, whose accessibility proxies hide the service PID. The outer sheet still supplies scope and geometry. Compact Cancel, Unicode, physical keys and Escape pass on macOS 26 and 27. Expanded-panel acceptance is still in progress.

iPhone 73 defers keyboard-dismissal state changes until focus settles and ignores a stale dismissal after reopening. Two native regressions failed before correction; seven keyboard tests and the actual keyboard UI passed afterward without the SwiftUI state-update warning. Final integration CI is pending.

Four native SessionView tests pass: zoom/pan/Fit and off-center taps, hold-drag/release, software typing, keyboard controls and overlay dismissal. They use rendered screenshot targets and public XCUITest gestures. They do not prove physical iPhone scrolling, network handover or all-network latency. The default CI unit scheme is unchanged; the dedicated `WAIRemotePhoneInteraction` scheme provides the full-screen tests.

Release packaging, distribution and live Mini acceptance are pending. The normal Mac feed remains 74; iPhone TestFlight remains 72. Mac 75 was a preview and was not promoted.

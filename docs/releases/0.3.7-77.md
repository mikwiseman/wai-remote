# WAI Remote 0.3.7 — Mac 77

Full-desktop clicks now activate the selected application when WAI Remote is in the background. Build 76 could raise its window while the previous application kept focus. The correction sets Accessibility Frontmost only on the already validated window owner; window grants retain background input and the physical pointer stays independent.

Regression tests first reproduced the failure with a regular background host, a separate target application and a third foreground application. The correction passed native button and raw-pointer clicks, the actual unsaved-document Cancel panel and a SwiftUI menu picker. Existing selected-window, frame and session checks remain. Hover, scrolling and held drags do not activate another application.

Mac 76's save-panel and menu ownership fixes remain included. iPhone 0.3.7 (73) is already available in the existing internal TestFlight group and is unchanged by this Mac update. Physical iPhone scrolling remains an acceptance check, not a claimed result of native fixtures.

Release gates: exact-source CI, signed universal app and DMG, notarization and mounted-app validation, real Sparkle installation with saved access unchanged, then Mini input and reconnection acceptance.

# WAI Remote 0.3.7 — Mac build 68

Connections go peer to peer, also across the internet. Each device learns its
public address from STUN servers in Moscow, which a VPN used in Russia reaches
directly, so two Macs on different home networks can connect without the
Helsinki relay. From those networks any foreign server was about 270 ms away
and Moscow 12–16 ms. 0.3.6 discarded the only reflexive address a VPN leaves
and therefore connected directly only inside one LAN.

The relay remains, over UDP only, for networks that cannot connect directly.
The TCP relay and the TCP-only diagnostic are gone from these apps.

Install this update on **both Macs**; peer to peer needs it on both ends. Older
apps keep connecting through the relay.

Validation: 184 package tests, the gateway race suite, the live gateway's
configuration, and an end-to-end offer under the VPN that keeps the public
reflexive candidate. A live session between two Macs on different networks is
still required to measure the direct path.

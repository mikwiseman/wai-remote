# WAI Remote 0.3.7 (69)

Verified 1 November 2026. Taps retain the initial finger position; two-finger scrolling uses the displayed desktop scale and a stable target. Pinch zoom stays anchored in portrait, landscape and keyboard layouts. The iPhone renderer restores its requested 60 Hz cadence after WebRTC initialization. Early ICE gathering now applies the same route filtering as the deadline path.

The Mac preserves fractional scroll movement and avoids a redundant WindowServer lookup. Background activation remains unchanged.

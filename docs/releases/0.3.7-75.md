# WAI Remote 0.3.7 — Mac 75 candidate, iPhone 72

Completes remote input support for macOS Save panels hosted in a separate process. Build 74 live Mini testing exposed the additional accessibility layer that ordinary modal-sheet tests did not cover.

The host now follows the selected sheet's accessibility bridge to its remote keyboard receiver while retaining the outer window for validation and pointer geometry. Button lookup stays within the hit sheet. Escape includes the character needed by background native key equivalents. Input does not activate another app or fall back to global injection.

29 native tests pass without skips, including a real NSSavePanel: Cancel, Escape, Unicode text, a physical key, and rejection after the outer sheet closes. This extends the existing modal and selected-window routing coverage.

Release acceptance is in progress. Build 74 remains published. Build 75 still requires signed-package checks, the local Sparkle update, CI, and live Mini verification of Delete and ordinary window controls. Physical iPhone acceptance remains separate from simulator coverage.

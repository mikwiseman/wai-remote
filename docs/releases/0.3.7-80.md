# WAI Remote 0.3.7 — Mac 80 candidate

Mac 80 is being prepared to correct a crash during remote desktop-click activation. A hidden window can expose a signed window number outside the valid WindowServer ID range. Converting it directly to an unsigned ID traps. The correction compares the selected ID in the signed domain, preserving exact matching without a narrowing conversion.

The crash was captured on the Mini's installed build 76. Build 79 contains the same conversion, so its green CI and successful MacBook installation did not establish Mini acceptance. Both conversion traps were reproduced with the original code. The corrected implementation passes two focused regressions covering deferred, negative, oversized and exact matching window numbers, without showing windows or sending input. Final release validation is pending.

Build 79's background activation, scoped hosted-control routing, popup selection, continued typing and bounded keyboard discovery remain included. The remote pointer stays separate, and single-window grants retain background input.

Release gates remain open: exact-source CI, signed/notarized universal artifact, public bytes and signatures, preserved access through Sparkle installation, and live Mini input/reconnection acceptance. Build 80 has not been built or published. Evidence will be recorded in `.runtime/agent80/` and `.release/publish-0.3.7-80/`.

iPhone 0.3.7 (73) remains the delivered TestFlight build. This Mac change does not update it. Physical iPhone scrolling and end-to-end latency remain unverified.

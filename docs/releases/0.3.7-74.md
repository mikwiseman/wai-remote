# WAI Remote 0.3.7 — Mac 74 candidate, iPhone 72

Adds the bundled [agent CLI](../AGENT_CONTROL.md) for Codex to inspect and control a saved remote computer through WAI Remote's existing viewer and permissions.

Build 73's installed-app test on the real Mini verified connection, click, exact single-line Unicode and scrolling, then exposed two existing input defects: multiline loss at native event boundaries and input targeting a parent window while a modal sheet is open. Build 74 isolates text control characters, preserving CRLF as one return, and resolves the selected document's attached sheet for input. Sheet buttons use their actual top-level accessibility element. Held keys keep their original target until release; there is no fallback to another document or global input.

The exact 40-line failure and CRLF regression were reproduced in an AppKit text view before the fix; 29 focused tests pass afterward. Another native regression reproduced the attached-sheet failure; 26 focused routing tests now pass, including actual sheet dismissal, cancellation and document isolation. Independent review passed. The sheet resolver's AX query budget is 10 ms, with 0.495 ms per lookup measured in the same-process fixture; this is not a foreign-app or end-to-end latency guarantee.

Build 73 was not promoted to the normal update feed. iPhone remains on the released scrolling update, build 72.

Release acceptance and delivery are pending.

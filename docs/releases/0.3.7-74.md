# WAI Remote 0.3.7 — Mac 74 candidate, iPhone 72

Adds the bundled [agent CLI](../AGENT_CONTROL.md) for Codex to inspect and control a saved remote computer through WAI Remote's existing viewer and permissions.

Build 73's installed-app test on the real Mini verified connection, click, exact single-line Unicode and scrolling, then exposed two existing input defects: multiline loss at native event boundaries and input targeting a parent window while a modal sheet is open. Build 74 is being prepared to address those defects. Build 73 was not promoted to the normal update feed. iPhone remains on the released scrolling update, build 72.

Release acceptance and delivery are pending.
